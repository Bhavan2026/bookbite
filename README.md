# 📚 BookBite – AI-Powered Document Processing Platform

BookBite is a web-based intelligent document processing platform that helps users extract, summarize, translate, and convert PDF content into speech.

## 🚀 Features

* 📄 PDF document upload
* 🔍 Text extraction from PDF
* 🤖 AI-based document summarization
* 🌐 Multi-language translation
* 🗣️ Text-to-Speech conversion
* 👁️ OCR support for scanned documents
* 📊 User dashboard
* 🔐 User authentication
* 📚 Document management
* 💡 Document recommendation

## 🛠️ Technologies Used

**Frontend**

* HTML
* CSS
* JavaScript

**Backend**

* Python
* Django

**AI / NLP**

* Natural Language Processing
* Text Summarization
* Qwen2.5-7B-Instruct-1M

**Document Processing**

* PyMuPDF
* Tesseract OCR

**Other**

* Google Translate
* Google Text-to-Speech (gTTS)

## 🏗️ Project Workflow

```text
User
  ↓
Login / Register
  ↓
Upload PDF
  ↓
Text Extraction / OCR
  ↓
AI Processing
  ↓
Summarization / Translation
  ↓
Text-to-Speech
  ↓
Result
```

## 🎯 Project Objective

The main objective of BookBite is to make large documents easier to understand by providing automated text extraction, summarization, translation, and audio conversion through a single web application.

## 💻 Installation

### Clone the repository

```bash
git clone https://github.com/Bhavan2026/bookbite.git
cd bookbite
```

### Create virtual environment

```bash
python -m venv venv
```

### Activate environment – Windows

```bash
venv\Scripts\activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run migrations

```bash
python manage.py migrate
```

### Start the server

```bash
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000/
```
